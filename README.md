# 🎄 Новогодний Квест 2026

Интерактивный новогодний квест для сотрудников компании!

## 🎮 Что внутри

- 5 этапов: загадки, викторина, игра на память, «собери слово», финальное задание
- Система очков и рангов
- Анимированные снежинки и праздничный дизайн
- Адаптивный интерфейс (работает на телефонах)

## 🚀 Как опубликовать

### Самый простой способ — Vercel (1 минута)

1. Зайдите на [vercel.com/new](https://vercel.com/new)
2. Войдите через GitHub
3. Перетащите папку проекта или импортируйте репозиторий
4. Нажмите **Deploy** — готово!

### GitHub Pages

1. Создайте репозиторий на GitHub
2. Запушьте код:
   ```bash
   git init && git add . && git commit -m "🎄 Квест"
   git remote add origin https://github.com/ВАШ_ЛОГИН/new-year-quest.git
   git push -u origin main
   ```
3. В Settings → Pages → Source → выберите **GitHub Actions**
4. Подождите 1-2 минуты

## 🛠 Локальный запуск

```bash
npm install
npm run dev
```
